Library files & device setup ↗

Saved poems and styles stay in this browser. Export the library to keep a copy or transfer it to your ESP32 project.

For the device: replace data/poetry.json with your export, run python3 scripts/generate_poetry.py, then build and upload.

This preview uses the device's bitmap font and software perspective projection. It does not emulate touch hardware or ESP32 frame rate.
